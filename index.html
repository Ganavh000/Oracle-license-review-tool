Methodology and limitations

  • Metric: Processor calculation only. Named User Plus and socket-based editions are not calculated.
  • Soft partitioning: enter all physical hosts that Oracle workloads could run on, subject to the applicable Oracle licensing policy and contract.
  • Hard partitioning: the tool can calculate a proposed partition-core basis, but it does not certify that the configuration qualifies. Contract/policy validation and evidence are required.
  • Core factor: factor must be supported by a verified Oracle Core Factor Table reference. Do not treat the default as authoritative.
  • Rounding: required processor licences are rounded up per environment after applying the factor.
  • DR / standby: the tool flags claimed exceptions for separate review; it does not automatically grant a DR licensing exception.
  • Commercial pricing: no hard-coded support percentage is used. Any list price or support estimate should be documented separately.
  • This is an internal calculation/workpaper aid, not legal advice or an Oracle licensing determination. Oracle contractual terms govern.
